# 关系评测实验室

本地优先的 S/D 独立答卷与来源合并工具。支持20题快速版和40题完整版、10/24题可选背景与家庭模块、事件归属快照及分段主观事件；镜像行为题在每道题下并排填写本人自评与对另一方的观察，按机制分组并显示各来源进度；`N` 用于无观察机会且不计分；不在浏览器外保存答案。新答卷使用v2格式，并兼容导入v1、旧v2及历史 M 文件，但不再新建 M 答卷。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm run dev
```

打开终端显示的本地地址。生产构建：

```bash
pnpm run build
pnpm run test
```

也可使用 npm；不要同时提交两套锁文件。平台是纯前端答卷层。导入答卷后会生成包含完整规则、量化口径和原始 JSON 的自包含评估文本，可直接粘贴给支持长文本的 AI，无需安装 `relationship-diagnosis` skill。构建前会从上级目录的 `standalone-prompt.md` 自动同步便携协议，避免两套规则漂移。

## 分享方式

- 内网或本机：运行开发/生产服务器，把地址发给同一可信网络内的参与者。
- 静态/边缘托管：部署本目录；答卷仍只在浏览器内处理，除非你自行加入后端。
- 无网页环境：把上级目录 `standalone-prompt.md` 中的完整代码块与答卷 JSON 一并交给 AI。

参与者应分别填写、使用同一会话编号、在提交前不查看他人答案，并通过可信渠道交换导出的 JSON 文件。
