# relationship-diagnosis

一套面向恋爱关系冲突、关系健康度、分手贡献、修复可能性、感情/继续意愿与核心兼容性的证据校准评估 Skill，并附带本地优先的独立答卷网页。

它的目标不是读取某人的“本质人格”，而是把可观察行为、当事人体验、解释、未知、互动循环、安全风险、修复记录和现实约束分开，再给出可解释、可证伪且有停止条件的判断。

> 本项目不是经过验证的心理量表、临床诊断、法律责任认定或紧急服务。出现暴力、性强迫、跟踪、限制自由、隐私勒索或报复风险时，应优先处理现实安全。

## 两种使用方式

### 1. 完整提示词：无需安装

适合任何支持长文本的 AI：

1. 打开问卷网页，独立完成 S 单视角或 D 双视角答卷。
2. 导出 JSON；D 模式双方应使用同一会话编号并在完成前互不查看。
3. 在“汇总答卷”中导入文件。
4. 选择“使用完整提示词”，复制全部文本。
5. 粘贴到一个没有此前关系讨论历史的新 AI 对话中。

便携协议的规则源是 [`standalone-prompt.md`](standalone-prompt.md)。网页构建时会自动同步该文件，避免页面与 Skill 形成两套标准。

### 2. Agent Skill：复杂材料更稳定

适合 Codex 或其他明确支持 Agent Skills 的环境：

```bash
git clone https://github.com/vh7t7gynrg-jpg/relationship-diagnosis.git ~/.codex/skills/relationship-diagnosis
```

也可以下载仓库 ZIP 后，把完整目录放入平台支持的 Skills 目录或按平台界面上传。不要只复制 `SKILL.md`，因为它会按情况读取量化、视角、安全、感情和证据参考文件。

调用示例：

```text
请使用 relationship-diagnosis skill 评估我接下来提供的独立答卷。
先核验会话编号、来源独立性与安全项，再输出固定量化摘要、问题机制比重、人物贡献、改善建议和最终结论。
```

## 主要能力

- S 单视角与 D 双视角来源隔离；兼容导入旧版 M 文件但不把它误称为完整多人评测。
- 20 题快速版、40 题完整版、10/24 题背景与家庭模块。
- 感情倾向、可观察投入、继续意愿和共同调整能力分别评估，不生成“真爱概率”。
- 按来源分开的关系功能指数、覆盖率、证据完整度、修复前景区间。
- 问题机制比重与人物可改变行为贡献分开，不从总分差直接定责。
- 安全风险单列，不用普通优点抵消暴力、强迫或控制。
- 最佳证据机制、竞争解释、逐项置信度和 2–4 周可证伪预测。
- 每方具体改善动作、观察指标和停止条件。

## 本地运行网页

需要 Node.js 22.13 或更高版本：

```bash
cd tester-site
pnpm install
pnpm dev
```

构建和测试：

```bash
pnpm build
pnpm test
pnpm lint
```

也可使用 npm。请保留现有锁文件，不同时提交多套锁文件。

## 数据与隐私

- 网页默认只在当前浏览器内处理答卷，不自动上传、不建立用户账户，也不提供云端查询。
- 刷新页面会清空未导出的内容；JSON 可能包含敏感关系信息，请使用代号并通过可信渠道传递。
- 上传给第三方 AI 前，应了解其数据政策，并删除姓名、账号、地址、单位、联系方式和私密影像。
- S 模式只能评价“若描述成立，该行为意味着什么”，不能冒充缺席方自评或读取其内心。
